Vaani Nudge — Filter Placeholder Requirements

Goal

Generate a natural Vaani nudge from the active filter value.

Example:

Cotton → Kya aap Cotton mein dekh rahe hain?

At runtime, the system receives only the filter value string. The implementation should therefore classify the value based only on its text.

Nudge Generation Logic

Apply the following rules in priority order.
First matching rule wins.

1. Price Range

Input format

₹ 300 - ₹ 399

Output

Kya aap ₹300 - ₹399 ke beech dekh rahe hain?

Detection

₹\s[\d,]+\s-\s₹\s[\d,]+

₹ → must contain the rupee symbol

\s → allows any number of spaces*

[\d,]+ → one or more digits or commas

\s-\s → a hyphen, with optional spaces around it

₹\s*[\d,]+ → another rupee amount

So it matches values like:

  • *₹300 - ₹399*

  • *₹ 300 - ₹ 399*

  • *₹1,000-₹1,499*

Extraction

Extract both numeric values and remove:

  • ₹

  • commas

  • extra spaces

2. Price — Under

Input format

Under ₹ 449

Output

Kya aap ₹449 tak dekh rahe hain?

Detection

(?i)under.₹\s[\d,]+

  • *(?i)* → case-insensitive, so Under*,* UNDER*,* under all match****

  • *under* → looks for the word “under”****

  • *. → allows anything between “under” and the ₹ symbol**

  • *₹* → requires the rupee symbol****

  • *\\s → allows zero or more spaces after ₹**

  • *[\\d,]+* → requires one or more digits or commas****

So it matches:

Under ₹449
 Under ₹ 449
 UNDER ₹1,499

Extraction

Extract the number after ₹.

3. Discount — Above

Input format

70% And Above

Output

Kya aap 70% se zyada discount dekh rahe hain?

Detection

(\d+)\s%.(?i)(above|or more)

  • *(\\d+)* → captures one or more digits, e.g. 70****

  • *\\s → allows optional spaces**

  • *%* → requires the percent symbol****

  • *. → allows any text after the percentage**

  • *(?i)* → makes the following match case-insensitive****

  • *(above|or more)* → requires either above or or more****

So it matches:

  • *70% And Above*

  • *20% above*

  • *50% or more ***

Extraction

Extract the number before %.

4. Price — Above

Input format

₹ 800 & Above

Output

Kya aap ₹800 se upar dekh rahe hain?

Detection

₹\s[\d,]+.(?i)(above)

Breakdown:

  • *₹* → requires the rupee symbol****

  • *\\s → allows optional spaces after ₹**

  • *[\\d,]+* → matches the price number, including commas****

  • *. → allows any text after the price**

  • *(?i)* → makes the next part case-insensitive****

  • *(above)* → requires the word above****

So it matches:

  • *₹800 & Above*

  • *₹ 800 And Above*

  • *₹1,499 above*

From ₹ 800 & Above, the extracted value is 800.

Extraction

Extract the number after ₹.

5. Rating — Above

This rule must use a strict whole-string match.

Input formats

  • 4.0 And Above

  • 3.5 and above

  • 2.0 & Above

Output

Kya aap 4.0 rating se upar dekh rahe hain?

Detection

^\d(.\d)?\s(and|&)\sabove$

Case-insensitive.

The regex must remain anchored to the complete value.

For example:

12 Years & Above

must not be classified as a rating.

6. Bare > Symbol (Weight / Capacity)

Input format

>2000gm

Output

Kya aap 2000gm se zyada dekh rahe hain?

Detection

^>\s[\d,]+\s(\w+)?$

  • *^* → start of the string****

  • *>* → the string must start with >****

  • *\\s → allows optional spaces after >**

  • *[\\d,]+* → matches one or more digits/commas, e.g. 500 or 1,500****

  • *\\s → allows optional spaces after the number**

  • *(\\w+)?* → optionally allows one word after the number****

  • *$* → end of the string****

So it would match:

  • *>500*

  • *> 500*

  • *> 1,500*

  • *>500 kg*

  • *> 10 Years*

Extraction

Extract the number and the unit after >.

Default Rule

If none of the numeric rules match, use the filter value directly.

Template

Kya aap {value} mein dekh rahe hain?

Examples:

  • Cotton → Kya aap Cotton mein dekh rahe hain?

  • Black → Kya aap Black mein dekh rahe hain?

  • Plus Size → Kya aap Plus Size mein dekh rahe hain?

  • 12 Years & Above → Kya aap 12 Years & Above mein dekh rahe hain?

  • Top Rated → Kya aap Top Rated mein dekh rahe hain?

  • Mall Brands → Kya aap Mall Brands mein dekh rahe hain?

Any value that does not match a numeric pattern should resolve through this fallback.

Classification Priority

  1. Price Range

  2. Price Under

  3. Discount Above

  4. Price Above

  5. Rating Above

  6. Generic Value

Always evaluate in this order.

Expected Input → Output

InputTemplate
₹ 300 - ₹ 399 Kya aap ₹300 - ₹399 ke beech dekh rahe hain?
Under ₹ 449 Kya aap ₹449 tak dekh rahe hain?
70% And Above Kya aap 70% se zyada discount dekh rahe hain?
₹ 800 & Above Kya aap ₹800 se upar dekh rahe hain?
4.0 And Above Kya aap 4.0 rating se upar dekh rahe hain?
Cotton Kya aap Cotton mein dekh rahe hain?
12 Years & Above Kya aap 12 Years & Above mein dekh rahe hain?

2. Nudge Construction

After classification, construct the nudge based on the number and type of filters.

2.1 Single Filter

If there is only one filter, use its standalone template.

Examples:

Filter Output
Cotton Kya aap Cotton mein dekh rahe hain?
Under ₹ 300 Kya aap ₹300 tak dekh rahe hain?
4.0 And Above Kya aap 4.0 rating se upar dekh rahe hain?

3. Two-Filter Joining Rules

Each filter must first be classified independently.

Then select the joining rule based on the pair of resulting types.

3.1 Label + Label

Join the two labels using ya.

Template

Kya aap {label1} ya {label2} mein dekh rahe hain?

Examples:

Cotton + Embroidery

→ Kya aap Cotton ya Embroidery mein dekh rahe hain?

Black + Floral

→ Kya aap Black ya Floral mein dekh rahe hain?

3.2 Label + Numeric

The label comes first.

Use:

Kya aap {label} mein {numeric_fragment} dekh rahe hain?

Examples:

Cotton + Under ₹300

→ Kya aap Cotton mein ₹300 tak dekh rahe hain?

Cotton + 4.0 And Above

→ Kya aap Cotton mein 4.0 rating se upar dekh rahe hain?

Cotton + ₹300 - ₹399

→ Kya aap Cotton mein ₹300 - ₹399 ke beech dekh rahe hain?

Cotton + 70% And Above

→ Kya aap Cotton mein 70% se zyada discount wale dekh rahe hain?

Ordering requirement

If the numeric filter is received first and the label second, reorder them while constructing the sentence.

Example input:

Under ₹300 + Cotton

Output:

Kya aap Cotton mein ₹300 tak dekh rahe hain?

3.3 Numeric + Numeric

Join the two numeric fragments using aur.

Do not use mein.

Template

Kya aap {numeric_fragment1} aur {numeric_fragment2} dekh rahe hain?

Examples:

₹300 - ₹399 + 4.0 And Above

→ Kya aap ₹300 - ₹399 ke beech aur 4.0 rating se upar dekh rahe hain?

Under ₹500 + 70% And Above

→ Kya aap ₹500 tak aur 70% se zyada discount wale dekh rahe hain?

Processing Flow

Implementation should follow this sequence:

Receive filter value(s)

    ↓

Classify each value independently

    ↓

Generate fragment for each value

    ↓

Check number of filters

    ↓

1 filter

→ Use standalone template

2 filters

→ Determine pair type

    ↓

Label + Label

→ join with "ya"

Label + Numeric

→ label first + numeric fragment

Numeric + Numeric

→ join with "aur"

    ↓

Generate one final question

The Kya aap ... dekh rahe hain? wrapper must be applied once to the final nudge.

Do not create two standalone nudges and join them.

4. Skip following.

4.1 Bare Yes / No — Exclude, Don't Nudge

Input format

Yes / No

Rule

Skip nudge generation entirely for these — do not fall back to the Default Rule.

Reason

These are answers to an attribute question (e.g. "Washable: Yes/No") that is not available at runtime, so the bare value is meaningless on its own.

4.2 Bare Numbers or Ranges With No Unit — Exclude

Input format

8

40

100 - 149

Rule

Skip nudge generation if the trimmed value contains only digits, decimal points, hyphens, and spaces (no letters, no ₹, no %).

Warning

100 - 149 through 400 - 499 look identical to the Price Range ladder in Rule 1 but are actually bedsheet thread-count values from a different filter. Do not loosen the Rule 1 detection to match hyphenated numbers without the ₹ symbol.

4.3 Comma / Slash-Joined Values — Skip

Input format

Cotton, Polyester

Rule

Skip

4.4 Very Long Labels — Skip

Input format

Exercise & Fitness Active Knickers & Bras

Rule

Skip nudge generation for values longer than approximately 35 characters. A long compound label produces a run-on voice nudge.

4.5 Stray Whitespace & Invisible Characters — Always Clean

Rule

Trim leading and trailing whitespace and strip invisible Unicode formatting characters before applying any template. The source data contains both (e.g. a left-to-right-mark character before "Stainless Steel", and trailing spaces on a few brand names).
